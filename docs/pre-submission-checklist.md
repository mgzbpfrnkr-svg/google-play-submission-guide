# Google Play Submission Checklist

## 1. Before building the release
- [ ] App is fully tested
- [ ] No major crashes or ANRs
- [ ] Release build works without debug features
- [ ] Version code is increased
- [ ] Version name is correct
- [ ] Package name is final
- [ ] Signed APK/AAB is ready
- [ ] No test data remains in production
- [ ] App is optimized for performance

## 2. Store setup
- [ ] Google Play Console account is active
- [ ] Developer account is verified
- [ ] App is created in Play Console
- [ ] Contact details are filled
- [ ] Privacy policy URL is added
- [ ] App category is chosen
- [ ] Target audience is selected

## 3. App listing
- [ ] App name is complete
- [ ] Short description is ready
- [ ] Full description is ready
- [ ] App icon is uploaded
- [ ] Screenshots are uploaded
- [ ] Feature graphic is uploaded
- [ ] App category is selected
- [ ] Language is configured

## 4. Privacy and safety
- [ ] Privacy policy exists and is public
- [ ] Data Safety form is completed
- [ ] Permissions are justified
- [ ] No unnecessary permissions requested
- [ ] User data handling is clear

## 5. Release submission
- [ ] AAB/APK is uploaded
- [ ] Release notes are written
- [ ] App access settings are complete
- [ ] Content rating is filled
- [ ] All required forms are complete
- [ ] Review is triggered

## 6. After submission
- [ ] Track review status
- [ ] Read Play Console feedback
- [ ] Fix any rejection reasons
- [ ] Upload a new version if necessary
- [ ] Publish once approved
